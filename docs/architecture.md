# 架构与行为边界

```text
应用按键 → 小狼毫 TSF → WeaselServer / RimeWithWeaselHandler → librime
                                │                          ↓
                                │                  当前拼音与本页候选
                                ↓                          │
                        TypePick WeaselBridge ←─────────────┘
                                │ 快照 + revision
                                ↓
                      Selector 单工作线程 / 防抖
                                ↓
                    WinHTTP → Jev Choice / abstain
                                ↓
                校验答案 → 丢弃旧 revision → UI 线程定时取结果
                                ↓
                 二次校验快照 → 独立无焦点推荐窗口
                                ↓ Tab
                再校验快照 → Rime 选中本页候选 → 原上屏通道
```

TypePick 不自行实现 TSF，不改变 Rime 原候选顺序，也不把网络调用放进按键线程。

## 状态与撤销

- 每次按键按下先撤销旧推荐，再由 Rime 处理；适合推荐的拼音按键处理后提交新快照。
- 快照包括 Rime session、原始输入、候选页码、组合串光标/选择范围、上下文、候选文本列表。
- 每次提交或撤销递增 revision。后台最多一个请求执行，新输入覆盖待处理项；已有请求可以结束，但过期答案不能显示或上屏。
- 显示推荐和按 Tab 时，均重新读取 Rime 快照并逐项匹配。Tab 接受时调用 `select_candidate_on_current_page`，上屏仍走小狼毫 `_Respond`，并消耗对应 Tab 松开事件。
- 焦点、会话、换页、鼠标选词、配置选项变化及部署维护都会撤销；导航/快捷键及光标跨行清空上下文。同一行内仅鼠标移动但没有失焦通知时，尚不能可靠识别，这是当前上下文准确性的限制。

## 模型契约

默认固定模型 `jev-1.13.0`。请求中每个候选对应 `c0`…`cN`，另有 `abstain`。答案必须满足完整概率表、概率范围及总和、已知选择 ID、置信度至少 0.7、所选概率比次高值至少高 0.1。失败不改候选、不自动上屏。

默认防抖 150 ms、结果有效时限 600 ms。WinHTTP 各阶段按剩余时间设置超时，超过时限的结果丢弃；它不是硬实时网络取消，工作线程及退出等待可能超过单一时限。UI 按键处理不等待请求结束。

## 数据与密钥

开关默认关闭；应用匹配只接受 `notepad.exe`，未知应用拒绝。此限制不是完整的敏感文本检测，记事本内容也可能敏感。暂不支持用户随意增加浏览器、密码管理器等应用。

只累计本段 Rime 上屏文本，不通过剪贴板、UI Automation 或文档接口取文。上下文只在内存中存在，不写输入历史文件；Jev 请求由用户显式启用。密钥只在服务端环境中读取，请求目标固定为官方 HTTPS 主机，禁用重定向，不输出请求头或响应原文。

本地 `demo` 仅用两个预设场景验证接口，与模型效果严格区分。默认词库为自编测试夹具，不承担完整中文输入能力；生产使用继续沿用 Rime 的已部署方案，并单独确认词库许可证。
